# OMX 동역학 실험실 확장 설계: 기구학 단원 + 동역학 심화 + 번호 재정리

작성 2026-11-21. 대상 사이트 소스 `~/isaac/omx_isaac_lab/omx-lab/` (배포: langpeu.github.io 저장소의 `omx-lab/`).

## 1. 목적 (왜)

- 사용자는 로봇 동역학 입문자이고, 이 실험실로 **동역학 개념을 하나씩 익히는 것**이 목표. 나중에 학습자료로 공개하고 유튜브 쇼츠로 알린다(아직 쇼츠는 만들지 않음).
- 현재 실험실(상황 1~10)은 관절 하나의 정역학·PD 제어·시뮬레이터 문제는 잘 다루지만,
  ① 동역학의 전제인 **기구학(FK/IK)** 이 없고, ② **자세별 관성 M(q), 관절 결합, 원심력, 적분 제어, 모터 특성, 힘 방향(Jᵀ·F)** 이 비어 있다.
- 쇼츠가 아직 없으므로 지금이 번호와 주소를 정리하기 가장 싼 때다.

## 2. 목표 / 비목표 / 반목표

**목표**
- 번호 순서대로 풀면 배우는 순서가 되도록 21개 상황을 단원으로 정리한다.
- 새 상황 11개를 기존과 같은 형식(1 개념 → 2 예측 → 3 실험 → 4 확인, 필요하면 5 응용)으로 추가한다.
- 주소에서 번호를 빼서, 앞으로 문제를 끼워 넣어도 주소가 바뀌지 않게 한다.

**비목표**
- 운동방정식 유도(라그랑주, 뉴턴-오일러) 자체를 가르치는 페이지. (필요하면 기초 개념에 짧은 설명만)
- 6자유도 일반 IK, 궤적 최적화, 강화학습.
- 원본 실습 문서(Claude Docs)의 상황 번호를 바꾸는 것. 문서는 그대로 두고 실험실만 바꾼다.

**반목표 (기술적으로 돌아가도 실패인 것)**
- 손계산 식과 시뮬 결과가 안 맞는 문제. 모든 문제는 **예측이 시뮬과 정해진 허용오차 안에서 맞아야** 공개한다.
- 받침대처럼 현실에 없는 인위적 물체로 결과를 맞추는 것 (사용자가 싫어함).
- 결과가 "느낌"으로만 끝나서 채점할 숫자가 없는 문제.

## 3. 제약

- 브라우저 MuJoCo 3.17.0 WASM + three.js r128, 빌드 도구 없음(정적 파일). 서버 없음, `file://` 에서는 동작 안 함.
- 모델: ROBOTIS `open_manipulator` 의 OMX (`model/omx_lab.xml`, `tools/build_xml.py` 로 생성). 원본 저장소는 수정하지 않는다.
- 서보 값: ROBOTIS 공식 스펙표(2026-11-21). OMX-AI 는 XL430 12 V(1.5 Nm, 61 rpm, 1.4 A 스톨), XL330 5 V(0.52 Nm, 104 rpm). 11.1 V 값은 쓰지 않는다.
- 배포 저장소의 htmlproofer(3.19.4, `--check-html`)를 통과해야 한다. 배포는 repository_dispatch 로만 실행, push 전 `git pull --rebase`.
- 코드나 파일을 만들기 전에 사용자에게 확인한다(작업 노트 규칙). 한 상황씩 끝까지 완성한 뒤 다음으로.

## 7. 2단계: 새 상황 (하나씩, 손계산 ↔ 시뮬 확인 후 공개)

공통: 각 상황마다 먼저 Node(MuJoCo WASM)로 손계산 값과 시뮬 값을 맞춰 보고, 허용오차와 실험 조건을 정한 뒤 페이지를 만든다. 아래 숫자 중 "확인 필요"는 아직 시뮬로 검증하지 않은 값이다.

모델 치수 (model/omx_lab.xml 에서 읽음):
- joint2 → joint3: (x 0.0415, z 0.11315) → 길이 0.1205 m, 수직에서 앞으로 20.1° 기울어짐
- joint3 → joint4: 0.162 m (x 방향)
- joint4 → 손끝(end_effector): 0.0287 + 0.09193 ≈ 0.1206 m
- joint2 높이: link1 0.034 + 0.0635 (link0 기준)
- armature: joint1~3 0.005, joint4~5 0.001 kg·m². damping 0.2 / 0.05, frictionloss 0.1

### 1 FK (`fk/`)
- 개념: 관절 각도 → 손끝 위치. 평면 3링크(joint2·3·4), joint1 은 평면 회전. 각도는 누적해서 더한다.
- 예측: 주어진 (joint2, joint3, joint4) 에서 손끝 (x, z). 처음은 쉬운 자세, 다음은 20.1° 오프셋이 효과를 내는 자세.
- 실험: 각도 입력 → 팔이 그 자세로 → 손끝 위치(사이트) 표시. 채점 ±5 mm.
- 응용: joint1 을 돌리면 (x, y) 로 퍼지는 것.
- 함정: 위팔의 20.1° 기울어짐, deg/rad.

### 2 IK (`ik/`)
- 개념: 손끝 목표 → 관절 각도. 손목 수평 조건으로 2링크 문제로 줄인 뒤 코사인 법칙. 답 2개(팔꿈치 위/아래), 닿지 않는 곳.
- 예측: 목표 공 (x, z) → joint2, joint3 (손목 각도는 수평 유지 조건으로 결정).
- 실험: 3D 에 목표 공, 예측 각도를 넣어 실행 → 손끝–공 거리. 채점 ±5 mm. 닿지 않는 공 하나 포함(“답 없음”을 고르게).
- 확인 필요: 관절 한계 안에서 팔꿈치 아래 해가 실제로 가능한 목표 위치.

### 3 손끝 속도와 특이점 (`singularity/`)
- 개념: v = J·q̇. 팔을 다 뻗을수록 같은 손끝 속도에 필요한 관절 속도가 커지고, 다 뻗은 상태(특이점)에서는 바깥쪽으로 못 움직인다.
- 예측: 손끝을 수평 바깥으로 일정 속도로 움직일 때, 거리 r 에서 필요한 joint 속도.
- 실험: 직선 궤적 추종, 관절 속도가 61 rpm(6.39 rad/s) 한계에 닿는 지점 측정.
- 연결: 다음 단원 Jᵀ·F 의 J 와 같은 것.

### 6 어느 방향으로 밀 때 제일 셀까 (`push/`)
- 개념: τ = Jᵀ·F. 같은 손끝 힘도 방향에 따라 관절별 토크가 다르다. 팔 방향으로 미는 힘은 관절 토크가 거의 안 든다.
- 예측: 자세 하나에서 수평/수직/팔 방향 힘 각각, 먼저 한계(1.5 / 0.52 Nm)에 닿는 관절과 그 힘.
- 실험: 손끝에 외력(xfrc_applied)을 점점 키워 무너지는 힘 측정. 채점 ±5 %.

### 9 뻗은 팔은 왜 느리게 돌까 (`inertia/`)
- 개념: I = Σ (링크 관성 + m·r²) + 모터 관성(armature). 같은 토크면 α = τ / I.
- 예측: 접은 자세와 뻗은 자세의 joint1 관성 → 같은 토크(예 0.5 Nm)로 90° 도는 시간 t = √(2θ/α).
- 실험: 두 자세 비교, `lab.fullM` 값도 보여 줌. 관절 마찰 0.1 Nm·damping 0.2 는 끈 상태가 기본(켜면 얼마나 느려지는지는 덤). 채점 ±5 %.
- 덤: armature 0.005 가 팔 관성의 몇 %인지 (뻗은 팔 joint1 I ≈ 0.0206 기준 약 24% — 확인 필요).
- 쇼츠 후보 1순위.

### 10 힘 빠진 팔 흔들기 (`pendulum/`)
- 개념: 토크를 끄면 팔은 진자. T = 2π√(I / (m·g·d)). I 와 g(q) 를 동시에 확인.
- 주의: joint2 는 바닥에서 약 0.1 m 높이라 위팔(0.12 m)을 아래로 늘어뜨리면 바닥에 닿는다 → **joint2 로는 진자를 만들 수 없음**.
  대신 위팔을 세우고 아래팔을 수평으로 둔 자세(joint4 높이 약 0.2 m)에서 **joint4(손목) 아래로 손(약 0.12 m)을 늘어뜨린 진자**로 한다. 나머지 관절은 위치 제어로 고정.
- 예측: joint4 에 매달린 손 부분(link5 + 그리퍼)의 작은 진폭 주기.
- 실험: joint4 모터만 끄고 살짝 밀어 주기 측정. joint4 armature 0.001, damping 0.05, frictionloss 0.1 이 주기와 감쇠에 주는 영향 — 마찰 끔/켬. 확인 필요: 마찰 0.1 Nm 가 손 무게 토크에 비해 커서 금방 멈추는지 (그러면 마찰 끔을 기본으로).

### 11 어깨를 돌리면 팔꿈치가 끌려간다 (`coupling/`)
- 개념: M(q) 의 대각선 밖 항. joint2 를 가속하면 joint3 에 −M₃₂·q̈₂ 토크.
- 예측: joint2 가속도 a 일 때 joint3 에 걸리는 토크, 약한 PD 에서 꺾이는 각도.
- 실험: joint3 을 약하게 잡고 joint2 급가속. 채점 ±10 % (확인 필요).

### 12 원심력은 무시해도 될까 (`centrifugal/`)
- 개념: C(q,q̇)·q̇. 뻗은 팔로 joint1 을 ω 로 돌리면 joint2 에 원심 토크 ∝ ω².
- 예측: 61 rpm 일 때 원심 토크 ÷ 중력 토크 비. 같아지는 ω.
- 실험: 일정 속도 회전 중 joint2 토크 변화. 결론 "OMX 속도에서는 작다"를 숫자로.

### 15 처짐을 I항으로 없애기 (`pid/`)
- 개념: 적분항이 오차를 쌓아 중력만큼 토크를 만든다. 대가: 느림, 오버슈트, 와인드업(포화 중 계속 쌓임).
- 예측: Ki 에 따라 처짐이 1/e 로 줄어드는 시간 (근사식, 확인 필요), 와인드업 후 튀는 크기는 정성 문제.
- 실험: 상황 14(처짐)와 같은 팔. 손끝을 잠시 막았다 푸는 버튼(막는 물체 대신 외력으로 표현 — 받침대 금지 규칙).

### 17 빠를수록 힘이 약해진다 (`speed-torque/`)
- 개념: DC 모터 τ_max(ω) = τ_stall·(1 − ω/ω_noload). XL430 12 V: 1.5 Nm, 61 rpm.
- 예측: 상황 16 의 0→90° 이동을 이 곡선으로 하면 최소 시간이 얼마나 늘어나는지.
- 실험: 토크 한계를 매 스텝 속도에 따라 바꿔 실행. 확인 필요: 실제 서보 곡선과 직선 근사의 차이는 본문에서 언급만.

### 18 서보가 뜨거워지는 이유 (`current/`)
- 개념: 토크 ∝ 전류 (XL430 1.5 Nm / 1.4 A ≈ 1.07 Nm/A). 멈춰서 버텨도 전류가 흐르고 열이 난다. 기계 출력 τ·ω.
- 예측: 상황 4 의 뻗은 자세를 버틸 때 전류, 스톨 전류 대비 %.
- 실험: 자세별 joint2 토크 → 전류 계기판. 공식 스펙표 값 사용.

### 도구: FK·IK 계산기 (`tool-kinematics/`)
- OMX 치수 기본값, 각도 ↔ 손끝 위치, 두 IK 해 표시, 작업 공간 그림. 상황 1·2 를 푼 뒤 쓰도록 링크.

### 기초 개념 추가
- 기구학 용어: 링크 길이, 작업 공간, FK/IK, 자코비안 J, 특이점. 단위 표 그대로.

## 8. 진행 순서

1. 1단계(번호 재정리) → 확인 → 커밋·push → 사용자가 배포.
2. 새 상황: 1 FK → 2 IK → 9 관성 → 10 진자 → 15 PID → 3 특이점 → 6 힘 방향 → 17 토크-속도 → 11 결합 → 12 원심력 → 18 전류. 도구 FK·IK 는 2 다음.
   각 상황: Node 로 수치 확인 → 사용자에게 수치·실험 조건 보고 → 페이지 작성 → 브라우저 확인 → (모아서) 배포.
3. 11, 12, 18 은 앞 상황들을 해 본 뒤 빼도 된다(준비 중 카드로 남기거나 목록에서 제거).

## 9. 빌더에게 맡기는 것 (Claude 판단으로 정한 것)

- 단원 이름, 폴더 이름(영문 짧은 이름), 첫 화면 단원 표시 방식.
- 이전 주소는 새 주소로 보내는 페이지로 남김 → (사용자 결정) 삭제함.
- 허용오차는 각 상황 수치 확인 후 정하되 기본 ±5 %(위치는 ±5 mm).
- 저장 키를 이름 기준으로 바꾸면서 기존 진행 기록은 옮기지 않음(공개 직후라 사용자 거의 없음).
