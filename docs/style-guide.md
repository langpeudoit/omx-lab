# 피지컬AI 실험실 스타일 가이드 (글꼴·크기·색)

2026-11-22 정함. 값은 `site/common/lab.css` 맨 위 `:root` 에 변수로 있고, 새 페이지·CSS 는 이 변수만 쓴다.
눈으로 보는 견본: `site/tools/style-guide.html` (배포 안 됨, 로컬 http://localhost:8765/tools/style-guide.html).

## 1. 글꼴

| 용도 | 글꼴 | 굵기 |
|---|---|---|
| 제목·본문·버튼 등 모든 글 | 나눔스퀘어 네오 `NanumSquare Neo` | 보통 400 · 굵게 700 · 제목 800 |
| 숫자 결과, 식, 입력칸 숫자, 표의 숫자 | JetBrains Mono `--font-mono` | 400 · 600 |

- 글꼴은 하나만 쓴다. 예전 제목용 Space Grotesk 는 한글이 없어 한 제목 안에서 글꼴이 섞였음 → 뺌. `--font-head` 는 `--font-body` 와 같음.
- 나눔스퀘어 네오 원래 배포본은 보통=300, 굵게=500, 더 굵게=700 이라 그대로 쓰면 본문이 굵게 나온다.
  `lab.css` 의 `@font-face` 에서 **표준 번호(400/700/800)로 다시 붙였으니** CSS 에는 400/700/800 을 쓴다. 600 을 쓰면 700(굵게)으로 보인다.
- 불러오는 곳: jsdelivr 배포본(`eunchurn/NanumSquareNeo@0.0.6`, woff2, 굵기 하나 약 390 KB, 세 굵기 약 1.2 MB).
  네이버 공식 주소(hangeul.pstatic.net)는 다른 사이트에서 불러오지 못하게 막혀 있음.
- 한국어 줄바꿈은 낱말 단위: `body { word-break: keep-all; overflow-wrap: break-word; }`

## 2. 글자 크기 (6단계, 이 밖의 크기는 쓰지 않음)

| 변수 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `--fs-h1` | 30px | 800 | 페이지 제목 (한 페이지에 하나) |
| `--fs-h2` | 20px | 800 | 카드 제목, 첫 화면 단원 제목 |
| `--fs-lg` | 17px | 400 (핵심어 700) | 본문 문단, 페이지 소개, 카드 안 목록, 소제목(h3, 800) |
| `--fs-md` | 16px | 400 · 700 | 버튼, 입력칸, 고르기 문항. body 기본 크기 |
| `--fs-sm` | 14px | 400 | 참고(.note)·판정(.fb) 문구, 표, 라벨, 링크 줄(.basics-link), 펼치기 제목 |
| `--fs-xs` | 13px | 400 · 700 | 계기판 이름, 표 머리, 칩, 범례, 경로 줄, 힌트, 사이드바 단원 이름 |

예외(숫자 강조): 계기판 숫자 1.15rem, 결과 큰 숫자 1.3rem, 식 17px — 모두 고정폭 글꼴.
사이드바 항목은 15px(0.9375rem), 첫 화면 문제 제목은 18px(1.125rem).

줄 간격·간격
- 본문 줄 간격 1.75, 보조 글씨 1.7, 제목 1.3~1.4
- 본문 한 줄 최대 60글자쯤 (`.card p { max-width: 60ch }`)
- 카드 안쪽 여백 24px 26px, 카드 안 간격 14px, 카드 사이 20px
- 시뮬레이션 칸 : 글 칸 = 0.9 : 1.1

## 3. 색

글자는 **회색 3단계 + 강조 파랑 하나**. 색은 의미가 있을 때만 쓴다.

| 변수 | 밝은 화면 | 어두운 화면 | 쓰는 곳 |
|---|---|---|---|
| `--ink` 진하게 | `#111821` (17.9:1) | `#f1f4f7` (14.7:1) | 제목, 핵심어(굵게), 숫자 결과, 표의 숫자 |
| `--text` 본문 | `#333d48` (11.0:1) | `#d3dae1` (11.5:1) | 설명 문단, body 기본 글자색 |
| `--muted` 보조 | `#5f6b78` (5.4:1) | `#9aa6b2` (6.6:1) | 참고, 표 머리, 라벨, 계기판 이름, 페이지 소개 |
| `--accent` 강조 파랑 | `#1f6feb` (4.6:1) | `#5b9dff` (6.0:1) | 링크, 현재 단계, 선택, 모터 토크 |

괄호 안은 카드 바탕(흰색 / `#19212a`) 기준 대비. 모두 읽기 기준 4.5:1 이상.

의미색은 지금 값 그대로: 모터 토크 `--accent`, 중력 토크 `--gravity`(주황), 맞음 `--good`(초록), 틀림 `--bad`(빨강), 주의 `--warn`.

규칙
- **핵심어는 진한 색 + 굵게**로만 구분한다. 파랑·빨강으로 칠하지 않는다(링크·판정 색과 헷갈림).
- **파랑은 누를 수 있는 것**(링크, 현재 단계, 선택된 버튼)에만 쓴다.
- **글 안의 링크는 밑줄 없이 파랑 + 굵게(700)**. 마우스를 올리면 `-webkit-text-stroke: 0.6px` 로 획만 두꺼워진다(글자 폭이 그대로라 줄이 밀리지 않음). 밑줄은 한글 받침과 겹쳐 깨져 보여서 쓰지 않는다.
- 보조 회색은 한 카드 안에서 본문보다 적게. 보조 글씨가 많으면 다시 흐리고 난잡해 보인다.
- 지금처럼 거의 검정 하나로 제목·본문·핵심어를 다 쓰지 않는다(대비 16:1 로 너무 강하고 구분이 안 됨).

## 4. 새 페이지에서

- 크기는 `font-size: var(--fs-…)`, 색은 `color: var(--ink | --text | --muted)` 만 쓴다. `0.88rem`, `#333` 같은 값을 직접 쓰지 않는다.
- 페이지 머리 `<head>` 의 구글 글꼴 링크는 JetBrains Mono 만:
  `https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600&display=swap`
  나눔스퀘어 네오는 `lab.css` 가 불러온다.
