1. 글자 색 비교

왼쪽은 지금 사이트 색(제목·본문·핵심어가 모두 같은 거의 검정), 오른쪽은 제안 색(진하게 / 본문 / 보조 3단계)입니다.

2. 글꼴·크기

글꼴: 나눔스퀘어 네오 하나(보통 400 · 굵게 700 · 제목 800). 숫자·식만 JetBrains Mono. 줄바꿈은 낱말 단위(keep-all).

3. 색

글자는 회색 3단계 + 강조색 하나. 색은 의미가 있을 때만 씁니다. 대비는 지금 화면(밝게/어둡게)의 카드 바탕 기준입니다.

  • 핵심어는 진한 색 + 굵게로만 구분합니다. 파랑·빨강으로 칠하면 링크나 판정 색과 헷갈립니다.
  • 파랑은 누를 수 있는 것(링크, 현재 단계, 선택된 버튼)에만 씁니다.
  • 글 안의 링크는 밑줄 없이 파랑 + 굵게. 마우스를 올리면 글자가 더 두꺼워집니다(글자 폭은 그대로). 파랑을 링크에만 쓰기 때문에 밑줄이 없어도 구분됩니다.
  • 모터 파랑 · 중력 주황 · 맞음 초록 · 틀림 빨강은 계기판·그래프·판정에서 지금처럼 그대로 씁니다.
  • 보조 회색은 한 카드 안에서 본문보다 적게 씁니다. 보조 글씨가 많아지면 다시 흐리고 난잡해 보입니다.
